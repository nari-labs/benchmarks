# Nari Labs Benchmarks

Open-source TTS benchmarking tools from Nari Labs. Licensed under Apache-2.0.

See [`tts_bench/`](tts_bench/) for setup and usage instructions.

## Methodology

Results are defined by a pinned dataset, deterministic open-loop arrival and prompt streams,
client-observed streaming latency, playback continuity, and optional transcript quality. See
[`docs/tts_bench/methodology.md`](docs/tts_bench/methodology.md) for the complete measurement and
reproducibility contract.
